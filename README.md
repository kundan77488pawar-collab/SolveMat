# SolveMate AI starter
Includes Study, Farming, and Career/Skills categories.

Deploy by connecting this GitHub repository to Netlify so Netlify can build and publish the function.
In Netlify environment variables, add GEMINI_API_KEY privately. Never put API keys in this repository, HTML, or chat.
Review API availability, pricing, terms, and age requirements with a parent/guardian before setting up an AI provider account. This starter has no rate limiting or abuse protection yet; test only with non-sensitive sample questions and do not share widely until protections are added.
